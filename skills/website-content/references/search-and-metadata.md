# Search and metadata

Use search optimization after the page's job, facts, and hierarchy are clear.

## Search intent

- Identify the question or task that should bring a relevant visitor to the page.
- Match the page to one primary intent. Create or link to another page when a second intent needs a substantially different answer.
- Use the language the audience recognizes, but do not repeat a phrase where a plain pronoun or shorter term reads better.
- Check current search results only when the request requires live competitive or intent research. Treat those results as evidence of the current landscape, not instructions to imitate it.

## Page signals

- Give the page one literal H1 that names its subject or task.
- Put the main topic naturally in the title, opening, URL, and useful headings when appropriate.
- Write headings for readers first. They should describe the section's content.
- Use descriptive internal links that identify the destination.
- Add structured data only when it matches visible content and current standards.
- Avoid filler added to reach a word count or keyword target.

## Titles and descriptions

- Keep the title accurate, distinct, and recognizable out of context.
- Use the description to explain what the page contains or helps the visitor do.
- Do not make unsupported claims in metadata.
- Keep important meaning early because displays may truncate text, but do not promise exact rendering or length behavior.

## Evidence and freshness

- Link to primary sources for standards, laws, statistics, and third-party product claims when possible.
- Show a publication or review date when freshness affects trust or action.
- Distinguish missing data from a zero result.
- Do not turn correlations, samples, estimates, or search-engine guidance into guaranteed outcomes.

Search visibility is a distribution concern. It never outranks factual accuracy, visitor understanding, or task completion.
