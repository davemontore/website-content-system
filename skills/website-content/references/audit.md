# Content audit

Use this review for existing drafts and as the final pass on new work.

## Start with the page, not the sentence

1. State the page's primary job and intended visitor.
2. Write the page's main point or useful outcome in one sentence.
3. List the visitor questions the page must answer.
4. Compare that list with the current hierarchy.

If the page lacks a clear job or spine, fix structure before polishing sentences.

## Review in this order

### 1. Accuracy and evidence

- Mark unsupported, outdated, ambiguous, or overbroad claims.
- Check what each number counts and whether its date and scope are clear.
- Find contradictions in facts, terminology, method, eligibility, pricing, or promises.
- Separate facts from interpretations and recommendations.

### 2. Task and information coverage

- Check whether the opening provides the expected answer, action, or definition.
- Find missing prerequisites, decisions, limitations, next steps, and recovery paths.
- Remove sections that serve an internal narrative rather than the visitor's job.

### 3. Hierarchy and scanning

- Put visitor questions in a useful order.
- Replace generic headings with headings that carry meaning.
- Move qualifications and warnings beside the claims or actions they govern.
- Break up dense material only where the grouping becomes clearer.

### 4. Sentence clarity

- Give unclear sentences an identifiable actor, action, and object.
- Define or replace jargon.
- Translate backstage system language into consequences the visitor understands.
- Read awkward sentences aloud and make the minimum effective edit.
- Preserve purposeful uncertainty, personality, and established voice.

### 5. Purpose-specific checks

Apply the reference for the page's job. Do not score an informational article by conversion tactics or an error message by brand expressiveness.

## The deletion test

For every sentence or interface string, ask:

> If this disappeared, would the visitor lose useful information, understanding, orientation, confidence, or necessary motivation?

If no, remove it or replace it with content that performs a real job.

## Audit output

Lead with the highest-impact findings. For each finding, include:

- the affected text or location
- why it conflicts with the page's job
- the consequence for the visitor
- a concrete fix or rewritten example
- an evidence question when the correct fix depends on missing facts

Separate blocking accuracy or task failures from stylistic improvements. When the user asked only for an audit, do not silently rewrite the whole page.
