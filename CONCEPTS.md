# Concepts

Shared domain vocabulary for this project, entities, named processes, and status concepts with project-specific meaning. Seeded with core domain vocabulary, then accretes as ce-compound and ce-compound-refresh process learnings; direct edits are fine. Glossary only, not a spec or catch-all.

## Content model

### Page job

The change a web surface should help a visitor achieve, used to select its information hierarchy, writing method, and review criteria.

### Primary job

The page job that controls the content hierarchy and wins when a page's goals conflict.

### Secondary job

An additional page job that influences only the sections where it supports the primary job and does not override essential information.

### Surface

The website context being written, such as page content, navigation, interface language, reference material, instructions, editorial writing, or marketing copy, whose function shapes its clarity and tone requirements.
